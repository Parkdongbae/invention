# 💡 발명 도우미 웹앱

중학교 기술 수업용 발명 주제 발굴 도구. 일상 속 불편을 문제로 발견하고, 발명 아이디어로 키우고, 발명계획서 PDF까지 완성하는 원스톱 웹앱입니다.

SSI(학생발명아이디어경진대회) 수상작 **1,199작**의 발명 10계명·5W1H 분석 데이터가 내장되어 있습니다.

> 📄 사용 방법은 **`발명도우미_사용설명서.pdf`** (9페이지, 학생용+교사용)에 정리되어 있습니다.

## 주요 기능

| 메뉴 | 기능 |
|---|---|
| 🔎 문제 발견 | WHO·WHERE·WHAT 선택 3단계 → 문제 문장 자동 생성, SDGs 연계, 불편 정도 기록 |
| 💡 아이디어 | 발명 10계명 스파크 · SCAMPER 카드 · 랜덤 스파크, 5W1H, 키워드 자동 추출 |
| 🏆 수상작 탐구 | 수상작 1,199작 검색·필터, 상세(10계명 매칭 + 5W1H 분석) |
| 🌏 SDGs | SDG 6·7·11·12·13·14·15 카드 + 관련 수상작 연결 |
| 🃏 카드게임 | 역사 속 발명 카드로 10계명 맞히기 (매칭 / 뒤집기) |
| 🧑‍🔬 발명가 게임 | 발명가 119명(한국 24명) 데이터 기반 — 「누구게?」 단서 추리 퀴즈 · 한국 발명가 챌린지 · 발명품 스피드 퀴즈 · 발명가 도감(심화 스토리 10인 + 위키피디아 링크 94인) |
| 🚨 오류 신고 | 학생이 잘못된 정보를 학번·이름·화면과 함께 신고 → 구글시트 `공통_오류신고` 시트에 학급 구분 없이 기록, 교사용에서 확인 |
| 📜 특허 검색 | 키워드 추천 → KIPRIS·Google Patents 원클릭 |
| 📄 발명계획서 | 폼(진행률) → PDF(`학번이름_발명계획서.pdf`) → 선생님께 전송 |
| 📓 발명 노트 | 자동 저장, 마크다운 내보내기 |
| 🎖️ 내 발명가 | 레벨·XP, 도장 16종, 통계, JSON 백업 |
| 🧑‍🏫 교사용 | 학급 설정, **저장된 반 전환(다중 학급)**, 구글시트 연동, **학생 초대 링크·QR**, **받은 계획서 내용 보기(전체화면·글자 크기 조절)**, 발표 순서, 피드백, **오류 신고 확인**, CSV |

- 🔊 **효과음**: 저장·도장·레벨업·게임 정답/오답·스파크에 효과음 (WebAudio 합성 — 오디오 파일 없음). 헤더의 🔊 버튼으로 on/off.
- 💬 **오늘의 발명 명언**: 홈에 매일 바뀌는 명언 20선 게시 (quotes_20.md).
- 🌐 수상작 탐구에 SSI 대회 공식 사이트(ssicompetition.com) 링크.
- 🎮 게임화: 행동마다 XP·도장 지급 (Lv.1 견습생 → Lv.5 마스터 발명가, 도장 16종)

## 실행 방법

```bash
cd app
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 프로덕션 빌드 → dist/
npm run preview  # 빌드 결과 미리보기 (http://localhost:4173)
```

## 배포

`dist/` 폴더만 정적 호스팅에 올리면 됩니다 (`base: './'`, Hash 라우팅 — 서버 설정 불필요).

- **GitHub Pages**: `dist` 내용을 `gh-pages` 브랜치에 푸시
- **기타 정적 호스팅**: dist 폴더 업로드

학생 데이터는 **각 기기 브라우저(LocalStorage)에 저장**됩니다. 백업은 프로필 페이지의 "모든 데이터 내보내기(JSON)".

## 구글시트 연동 + 학생 연결 흐름 (교사)

1. [sheets.new](https://sheets.new)에서 시트 생성 → 확장 프로그램 → **Apps Script**
2. 교사용 화면의 스크립트를 복사·붙여넣기 → 배포(웹앱, 액세스: 모든 사용자)
3. 웹앱 URL을 교사용 설정에 붙여넣고 저장 → 🔌 연결 테스트
4. **🔗 학생 초대 링크 · QR** 카드가 자동 생성됨
   - 학생은 **링크 클릭(또는 QR 스캔) → 「우리 반에 연결하기」 한 번** — GAS URL을 입력할 필요 없음
   - 링크를 못 쓰면: 학생이 발명계획서 → 선생님께 보내기 → URL 직접 붙여넣기
5. 학생이 「📨 선생님께 보내기」 → 시트 `{학급코드}_data`에 자동 기록
6. 교사용 **📥 받은 발명계획서** → 「🔄 구글시트에서 불러오기」로 **모든 학생 기기의 제출물을 모아서 내용까지 확인** (카드 클릭 = 계획서 전체 보기, PDF로 저장 가능)

## 교사용 단독 실행 파일 (exe)

```bash
powershell -ExecutionPolicy Bypass -File teacher-exe\build.ps1   # app/dist 빌드 후 실행
```

- `teacher-exe/발명도우미_교사용.exe` (약 2MB) — 앱 전체를 내장한 단독 실행 파일
- 더블클릭 → 로컬 서버(127.0.0.1:4174) 시작 + 브라우저 자동 오픈, 검은 창을 닫으면 종료
- Windows 기본 .NET Framework(csc)로 컴파일 — 설치·인터넷 불필요

## 데이터 파이프라인 (참고)

```bash
node scripts/parse-ssi.mjs        # inven10.md + 5w1h.md → app/src/data/ssiAwards.json
node scripts/parse-inventors.mjs  # inventors_with_flags_education.md + inventors_detailed_10.md → app/src/data/inventors.json
node scripts/verify-wiki.mjs      # 한국어 위키백과 문서 존재 실검증 → wiki 필드 주입 (인터넷 필요)
```

- SSI 수상작: 원본 1,202개 중 표 헤더 아티팩트 3건 제외 → **1,199작** (10계명·5W1H 100% 병합, 카테고리 자동 태깅)
- 발명가: **119명**(한국 24명, 심화 스토리 10인 병합, 국기·분야·생몰연도 파싱)
