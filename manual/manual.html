2학생 사용 가이드

① 문제 발견 — 발명의 씨앗 찾기

  1. 1누구를 위해? — 불편을 겪는 사람을 고르세요. (학생, 장애가 있는 사람, 어린이…)
  2. 2어디서? — 불편한 장소를 고르세요. (학교·교실, 집·주방, 길·도로…)
  3. 3무엇이 문제? — 문제 종류와 얼마나 불편한지 고르면 문제 문장이 자동으로 만들어져요. 문장은 자유롭게 고칠 수 있어요.
  4. 4💾 문제 발견 저장하기를 누르면 XP+10과 도장이 지급돼요.
💡 문제가 SDGs 목표와 관련 있으면 지구 목표 카드가 나타나요. 눌러서 연결해 두면 SDGs 탐구와 이어집니다.

② 아이디어 공방 — 아이디어 키우기

  • 🧭 발명 10계명: 무작위 계명 카드가 질문을 던져요. 메모도 가능해요.
  • 🧩 SCAMPER: 7장의 카드(대체·합치기·응용·크기·용도·없애기·뒤집기)를 눌러 메모를 남기세요.
  • 💥 랜덤 스파크: 버튼 한 번으로 "누가+어디서+무엇을+계명+SCAMPER" 조합 씨앗이 팝! 비슷한 실제 수상작 예시도 함께 보여줘요.
  • 제목과 한 줄 요약을 쓰고 💾 아이디어 저장 — 키워드는 자동으로 뽑아줘요. 5W1H를 6개 모두 채우면 도장!

③ 수상작 탐구 — 실제 수상작에서 배우기

  • 검색창에 우산, 배수로 등 키워드를 넣거나, 연도·수상·10계명·카테고리로 필터하세요.
  • 카드를 누르면 수상등급·작품 정보 · 발명 10계명 해석 · 5W1H 분석이 나타나요.
  • 상세 화면의 📜 특허 검색해 보기를 누르면 제목 키워드로 특허 검색까지 연결돼요.

④ 발명계획서 작성 · PDF · 제출

  1. 아이디어 목록의 발명계획서로 이어가기를 누르면 내용이 자동으로 채워져요.
  2. 학번·이름·반을 쓰고 15개 항목을 채우면 진행률 게이지가 100%가 돼요.
  3. 📄 PDF 내보내기 → 학번이름_발명계획서.pdf 파일로 저장! (발명가 인증 도장 포함)
  4. 우리 반에 연결된 상태라면 📨 선생님께 보내기로 제출 — 선생님 구글시트에 자동 기록돼요.
⚠️ 제출이 실패하면 기기에 대기로 저장됩니다. 인터넷이 연결되면 다시 보내기를 누르세요. 학번·이름을 채우지 않으면 PDF·제출이 막혀요.

⑤ 그 외 기능

  • 📓 발명 노트: 자유 기록. 800ms 후 자동 저장, 마크다운 파일로 내보내기 가능.
  • 🃏 카드게임: 역사 속 발명 이야기로 10계명 맞히기 — XP와 콤보가 쌓여요.
  • 🧑‍🔬 발명가 게임: 발명가 119명(한국 24명) 추리 퀴즈·발명품 퀴즈·도감. 외국 발명가는 이름(한글)로 표시되고, 도감에서 위키피디아 링크로 더 공부할 수 있어요.
  • 🚨 오류 신고: 화면에서 잘못된 정보를 발견하면 학번·이름·어느 화면인지 적어 신고하세요. 선생님 구글시트에 기록됩니다.
  • 🎖️ 내 발명가: 레벨(견습생→마스터), 도장 16종 수집, 모든 데이터 내보내기(JSON)로 백업.

3교사 사용 가이드

① 처음 설정 (1분)

  1. 1교사용 메뉴 → 학급 코드(예: 2-3)와 학급 이름 입력 → 저장.
  2. 2아래 구글시트 연동 진행 (없어도 발표 순서·피드백은 바로 쓸 수 있어요).

② 구글시트 연동 (학생 제출물 자동 수집)

  1. 1sheets.new에서 새 구글시트 만들기
  2. 2확장 프로그램 → Apps Script 열기
  3. 3교사용 화면의 ▼ 펼치기에 있는 스크립트를 복사해 전체 붙여넣기
  4. 4배포 → 새 배포 → 유형 웹앱, 다음 사용자로 실행: 나, 액세스 권한: 모든 사용자
  5. 5만들어진 웹앱 URL(https://script.google.com/…)을 교사용 설정에 붙여넣고 저장
  6. 6🔌 연결 테스트로 확인 — 시트에 {학급코드}_data 시트가 생기면 성공
⚠️ 스크립트를 수정했다면 배포 → 배포 관리 → 새 버전 배포를 해야 적용됩니다.

③ 학생 초대 링크 · QR — 학생 연결 방법

연동이 끝나면 🔗 학생 초대 링크 · QR 카드에 자동으로 링크와 QR이 만들어집니다.

학생 기기연결 방법
PC·태블릿 (크롬/엣지)알려준 초대 링크 클릭 → 「우리 반에 연결하기」 버튼 한 번
휴대폰·태블릿 카메라QR 스캔 → 같은 화면에서 연결
링크를 못 쓰는 상황학생이 발명계획서 → 선생님께 보내기 → URL 직접 붙여넣기
💡 학생은 GAS 주소를 입력할 필요가 전혀 없습니다. 링크 안에 연결 정보가 담겨 있어요. 학생 화면에는 「🏫 ○○반 연결됨」 배지가 표시되고, 배지가 있으면 제출 준비 완료입니다.

④ 받은 발명계획서 확인

  • 📥 받은 발명계획서 목록의 카드를 누르면 계획서 전체 내용이 화면에 나타나요.
  • 🔄 구글시트에서 불러오기를 누르면 모든 학생 기기에서 제출된 계획서를 시트에서 가져와 모아 보여줍니다 (출처 뱃지: 구글시트/이 기기).
  • 보기 화면에서 📄 PDF로 저장하면 그 계획서를 교사가 파일로 보관할 수 있어요.
  • 📤 CSV로 목록을 엑셀용 파일로 내보낼 수도 있습니다.

⑤ 발표 순서 · 피드백

  • 🎲 발표 순서: 이름을 한 줄에 한 명씩 넣고 순서 섞기 → 프레젠테이션 모드로 전체 화면 발표 진행(다음 버튼으로 명단 넘기기).
  • 📝 피드백: 발표자·제목·5개 항목(창의성·기능성·실용성·경제성·심미성) 별점·코멘트를 기록 → CSV 내보내기 지원.

⑥ 여러 반 수업하기 (학급 전환)

  1. 12-1반 정보를 넣고 💾 설정 저장 — 전환 목록에 자동 저장돼요.
  2. 22-2반 정보로 바꿔 다시 💾 설정 저장.
  3. 3수업 바꿀 때는 ⚙️ 학급 설정의 저장된 반 전환 리스트박스에서 반을 고르고 ▶ 이 반으로 전환 클릭!
  4. 4필요 없는 반은 🗑 반 삭제로 목록에서 제거할 수 있어요.
💡 전환하면 이후 학생 제출이 새 학급 코드로 기록됩니다. 이미 받은 계획서·신고는 그대로 보존돼요.

⑦ 오류 신고 확인

  • 학생이 🚨 오류 신고 메뉴에서 보낸 내용은 🚨 오류 신고 확인에서 볼 수 있어요.
  • 🔄 시트에서 불러오기를 누르면 모든 학생 기기의 신고가 학급 구분 없이 구글시트 공통_오류신고 시트에서 모아집니다 (학번·이름·화면·내용).
  • 카드를 누르면 신고 내용 전문 보기·복사, 📤 CSV로 내보내기가 가능해요.

4교사용 프로그램(exe) 실행 방법

발명도우미_교사용.exe는 앱 전체가 안에 담긴 단독 실행 파일입니다. 설치·인터넷 없이 노트북에서 바로 실행할 수 있어요.

  1. 1발명도우미_교사용.exe 더블클릭 → 검은 창(서버)이 열립니다.
  2. 2몇 초 후 기본 브라우저가 자동으로 열립니다. (주소: http://127.0.0.1:4174)
  3. 3앱을 다 썼으면 검은 창을 닫으면 서버도 꺼집니다.
⚠️ 첫 실행 시 Windows 보안 경고가 뜰 수 있어요. 추가 정보 → 실행을 눌러주세요. (네트워크가 아닌 내 컴퓨터 안에서만 동작합니다)
💡 exe 안에서 만든 교사용 데이터도 브라우저에 저장됩니다. 학생 초대 링크는 exe 주소(127.0.0.1) 기준으로 만들어지므로, 학생이 인터넷 주소로 앱을 쓴다면 학생용 앱 화면 안의 URL 붙여넣기 방법을 사용하세요.

5자주 묻는 질문

질문답변
내 데이터는 어디에 저장되나요?각 기기의 브라우저 안(LocalStorage)에 저장됩니다. 서버가 없어서 기기를 바꾸면 데이터가 따로예요. 🎖️ 내 발명가 → 모든 데이터 내보내기(JSON)로 백업하세요.
효과음이 거슬려요오른쪽 위 🔊 버튼으로 끌 수 있어요. 설정은 기기에 저장됩니다.
「선생님께 보내기」가 실패해요① 인터넷 연결 확인 ② 교사용의 웹앱 URL이 정확한지 확인 ③ 그래도 안 되면 기기에 대기로 남으니 나중에 다시 보내기를 누르세요.
학생이 다른 반 링크를 열었어요학생이 새 초대 링크를 다시 열어 연결하면 됩니다. 가장 마지막에 연결한 반으로 제출돼요.
시트에서 불러오기가 실패해요① 교사용 설정의 URL 저장 여부 ② GAS가 웹앱으로 배포되어 있는지 ③ 스크립트 수정 후 새 버전 배포 여부를 확인하세요.
