1교사용 열기와 처음 설정

교사용은 별도 화면이에요

학생용 앱에는 교사용 메뉴가 보이지 않습니다. 교사용은 아래 두 가지 방법으로만 사용하세요.

방법설명
① 운영 배포 주소 (권장)parkdongbae.github.io/invention-teacher — 인터넷만 되면 어디서든 교사용 메뉴가 모두 보여요. 학생 초대 QR도 이 주소에서 만드세요.
② 교사용 프로그램발명도우미_교사용.exe 더블클릭 → 브라우저 자동 열림 (8장). 인터넷 없는 교실용 — QR 사용 시 주의사항은 3장 참고.
💡 학생용 주소에는 교사용 메뉴가 없습니다. 학생 기기와 교사 기기의 역할이 분리되어 안전해요.

처음 설정

  1. 1교사용 → 학급 코드(예: 2-1)·학급 이름·구글시트 웹앱 URL 입력
  2. 2🌐 학생 접속 주소(선택) — 학생이 접속할 인터넷 배포 주소 입력. exe(127.0.0.1)로 앱을 열 때는 이 칸에 배포 주소를 넣어야 QR이 정상 동작해요 (3장).
  3. 3💾 설정 저장 — 저장하면 이 반이 전환 목록에도 자동 저장돼요 (5장).

2구글시트 연동

  1. 1sheets.new에서 새 구글시트 생성
  2. 2확장 프로그램 → Apps Script 열기
  3. 3교사용 화면의 ▼ 펼치기 스크립트를 전체 복사·붙여넣기
  4. 4배포 → 새 배포 → 유형 웹앱, 실행: 나, 액세스: 모든 사용자
  5. 5웹앱 URL을 교사용 설정에 붙여넣고 저장 → 🔌 연결 테스트
  6. 6시트에 {학급코드}_data 시트가 생기면 성공
⚠️ 스크립트 수정 후에는 배포 관리에서 새 버전 배포를 해야 적용됩니다.

3학생 초대 링크 · QR

  • 연동 완료 시 🔗 학생 초대 링크 · QR 카드가 자동 생성돼요.
  • QR을 클릭하면 크게 표시됩니다 — 프로젝터·전자칠판에 띄워 학생들이 스캔하게 하세요.
  • 학생은 링크 클릭(또는 QR 스캔) → 우리 반에 연결하기 한 번이면 연결돼요. GAS URL을 입력할 필요가 없어요.
  • 링크를 못 쓰는 학생은 학생용 앱 → 발명계획서 → 선생님께 보내기 → URL 직접 붙여넣기로 연결할 수 있어요.
⚠️ QR에는 앱을 연 주소가 그대로 담깁니다. 교사용 exe(127.0.0.1:4174)나 localhost에서 만든 QR은 그 컴퓨터 안에서만 열려요 — 학생이 스캔하면 「사이트에 접근할 수 없음」이 됩니다. 이때는 초대 카드 상단에 ⚠️ 경고가 표시돼요.
해결: ① 운영 배포 주소에서 QR을 다시 만들거나 ② 「⚙️ 학급 설정」의 🌐 학생 접속 주소에 배포 주소를 저장하세요 (반 전환해도 유지돼요).

4받은 발명계획서 확인

  • 📥 받은 발명계획서의 카드를 누르면 계획서 전체 내용이 표시돼요.
  • 보기 화면에서 A－ / A＋로 글자 크기 조절, 🖥️ 크게 보기로 전체 화면 열람이 가능해요 (빔 프로젝트 발표용).
  • 📄 PDF로 저장으로 교사가 파일을 보관할 수 있고, 📤 CSV로 목록 내보내기도 됩니다.
  • 🔄 구글시트에서 불러오기로 모든 학생 기기의 제출물을 모아올 수 있어요.

5여러 반 수업하기 (학급 전환)

  1. 12-1반 정보 입력 → 💾 설정 저장 (전환 목록 자동 저장)
  2. 22-2반 정보 입력 → 다시 💾 설정 저장
  3. 3수업 시간에 ⚙️ 학급 설정의 리스트박스에서 반 선택 → ▶ 이 반으로 전환
  4. 4불필요한 반은 🗑 반 삭제로 제거
💡 전환하면 이후 제출이 새 학급 코드로 기록됩니다. 이미 받은 계획서·신고는 보존돼요.

6발표 순서 · 피드백

  • 🎲 발표 순서: 이름 붙여넣기 → 순서 섞기 → 프레젠테이션 모드(전체 화면, 다음 버튼으로 진행).
  • 📝 피드백: 발표자·제목·창의성/기능성/실용성/경제성/심미성 별점·코멘트 기록, CSV 내보내기.

7오류 신고 확인

  • 학생이 학생용 앱의 🚨 오류 신고에서 보낸 내용이 🚨 오류 신고 확인에 표시돼요.
  • 🔄 시트에서 불러오기 → 구글시트 공통_오류신고 시트에서 학급 구분 없이 전체 신고를 학번·이름·화면·내용과 함께 모아옵니다.
  • 카드 클릭으로 전문 보기·복사, 📤 CSV 내보내기 가능.

8교사용 프로그램(exe)

  1. 1발명도우미_교사용.exe 더블클릭 → 서버 창 표시
  2. 2브라우저 자동 열림 (http://127.0.0.1:4174)
  3. 3종료는 서버 창 닫기
⚠️ 최초 실행 시 Windows 보안 경고가 뜨면 추가 정보 → 실행. 내 컴퓨터 안에서만 동작합니다.
💡 exe는 교사용 빌드(--mode teacher)로 만들어져 교사용 메뉴가 모두 보여요. 재빌드: app/dist를 교사용으로 빌드한 뒤 teacher-exe\build.ps1 실행.
⚠️ exe 주소(127.0.0.1)는 교사 컴퓨터에서만 열립니다. exe에서 학생 초대 QR을 만들려면 먼저 「⚙️ 학급 설정」의 🌐 학생 접속 주소에 운영 배포 주소(parkdongbae.github.io/invention-teacher)를 저장하세요.

9자주 묻는 질문

질문답변
학생 앱에 교사용 메뉴가 없어요정상이에요. 학생용 배포판에는 교사용 메뉴가 숨겨져 있어요. 교사는 exe 또는 교사용 빌드 주소를 사용하세요.
시트에서 불러오기가 실패해요① URL 저장 여부 ② 웹앱 배포 상태 ③ 스크립트 수정 후 새 버전 배포 여부를 확인하세요.
받은 계획서에 본문이 없어요요약 정보만 수신된 제출이에요. 학생이 다시 보내거나 시트를 확인하세요.
학생이 다른 반 링크를 열었어요올바른 반의 초대 링크를 다시 열어주면 마지막에 연결한 반으로 제출됩니다.
학생이 QR을 스캔해도 「접근할 수 없음」이 떠요QR에 교사 컴퓨터 주소(127.0.0.1·localhost)가 담긴 경우예요. 초대 카드에 ⚠️ 경고가 떠 있으면 이 경우입니다. 운영 배포 주소에서 QR을 다시 만들거나 🌐 학생 접속 주소를 저장하세요.
여러 학교 선생님이 같은 주소를 써도 되나요?됩니다. 데이터는 각자 기기에만 저장되고 시트 연동도 각자 자기 시트 URL을 연결해 서로 섞이지 않아요.
