2발명 여정 — 문제 발견부터 계획서까지

🔎 문제 발견 → 💡 아이디어 → 🏆 수상작 탐구 → 📄 발명계획서 → 📨 선생님께 제출

① 문제 발견

  1. 1누구를 위해? 불편을 겪는 사람 고르기
  2. 2어디서? 불편한 장소 고르기
  3. 3무엇이 문제? 문제 종류와 불편 정도 고르기 → 문장 자동 생성(수정 가능)
  4. 4💾 저장 → XP+10, 도장! SDGs 카드가 나오면 눌러서 연결

② 아이디어 공방

  • 🧭 10계명·🧩 SCAMPER 카드로 생각 넓히기
  • 💥 랜덤 스파크: 버튼 한 번으로 아이디어 씨앗 + 비슷한 실제 수상작 예시
  • 제목·한 줄 요약 쓰고 💾 저장 — 5W1H를 6개 채우면 도장!

③ 수상작 탐구 · 발명가 게임

  • 수상작은 검색·필터로 찾고, 카드를 누르면 10계명 해석과 5W1H 분석이 나와요.
  • 발명가 게임: 단서를 하나씩 공개하며 발명가를 맞히는 추리 퀴즈! 외국 발명가는 이름(한글)으로 표시돼요.
  • 발명가 도감의 📖 위키피디아에서 더 보기로 더 공부할 수 있어요.

④ 발명계획서 · 제출

  1. 아이디어의 발명계획서로 이어가기 → 내용 자동 채움
  2. 학번·이름·반 작성, 15개 항목 완성 → 진행률 100%
  3. 📄 PDF 내보내기 → 학번이름_발명계획서.pdf 저장
  4. 우리 반 연결 후 📨 선생님께 보내기 → 구글시트에 기록!
⚠️ 우리 반 연결이 안 되어 있으면 선생님이 알려준 초대 링크를 열거나, 보내기 화면에서 URL을 붙여넣으세요. 제출 실패 시 대기로 남으니 나중에 다시 보내기를 누르면 돼요.

3오류 신고 — 잘못된 정보 찾기

  1. 1메뉴의 🚨 오류 신고 열기
  2. 2학번·이름 입력 → 어느 화면인지 칩으로 선택
  3. 3어떻게 잘못되었는지 적고 📮 오류 신고하기
💡 신고는 학급 구분 없이 선생님 구글시트의 공통_오류신고 시트에 학번·이름과 함께 기록돼요. 잘못된 정보를 찾으면 도와주세요!
